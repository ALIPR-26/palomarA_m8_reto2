# palomarA_m8_reto2
Proyecto de ciencia de datos reproducible. Gapminder.

## Objetivos del proyecto

### Objetivo principal

Analizar la evolución y la relación entre diferentes indicadores socioeconómicos y demográficos a nivel mundial durante el periodo **1990-2019**, utilizando datos de Gapminder.

### Objetivos específicos

1. **Analizar la evolución temporal** de la esperanza de vida, el PIB per cápita, la fertilidad y la población a nivel mundial durante el periodo 1990-2019.

2. **Estudiar la relación entre el PIB per cápita y la esperanza de vida**, para comprobar si los países con mayores niveles de riqueza presentan también una mayor esperanza de vida.

3. **Analizar la relación entre la fertilidad y la esperanza de vida**, estudiando si los países con una mayor tasa de hijos por mujer presentan menores niveles de esperanza de vida.

4. **Estudiar la relación entre el PIB per cápita y la fertilidad**, para observar si existe una asociación entre el nivel económico de los países y su tasa de fertilidad.

5. **Comparar los indicadores entre los diferentes territorios**, permitiendo identificar diferencias en las condiciones socioeconómicas y demográficas.

### Alcance del análisis

El análisis se realiza sobre **193 territorios** y comprende el periodo **1990-2019**. Se utilizan cuatro indicadores principales:

- **PIB per cápita (GDP per capita)**
- **Esperanza de vida (Life expectancy)**
- **Población (Population)**
- **Hijos por mujer / fertilidad (Babies per woman)**

Los datos proceden de **Gapminder** y han sido previamente importados, revisados y depurados para obtener un conjunto de datos final preparado para el análisis.
